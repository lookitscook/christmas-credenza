# Christmas credenza — original tight-lights app

Extracted directly from the live app attached to this post:

> Tightened the strand against the branches, keeping uneven wrapping and varied bulb angles.

The scene is `christmas-credenza-tight-3d`. Its 28,447-byte JavaScript module was recovered through read-only inspection of the nested browser iframe, matched to the parent post text.

## Run

**Single file:** open `standalone.html` in a modern browser. It embeds all scene code, Three.js, and CSS. It needs no downloads, installation, account, or server. WebGL must be available.

**Local server:** with Node.js installed, open a terminal in this folder and run:

```sh
npm start
```

Open **http://127.0.0.1:4178/**. No `npm install` is needed for this command. Press Ctrl+C to stop the server.

Drag to orbit, scroll or pinch to zoom, and use **Run train / Pause train**. Reload to return to the original view. All textures and geometry are generated by the recovered scene code.

## Optional Vite workflow

Use Node.js 22.12 or newer. Installation requires internet access; the app itself does not.

```sh
npm install
npm run dev
```

To rebuild for a static web host:

```sh
npm run build
npm run preview
```

A verified production build is already included in `dist/`. Upload the contents of `dist/` to a static host. Build output is left unminified for inspection. The official WebAssembly compiler fallback is included in the development dependencies for systems where Vite's native compiler is unavailable.

## What changed for packaging

The runtime scene module has exactly one string substitution: the Three.js 0.160.1 CDN import points to `../vendor/three.module.js`. The single-file edition substitutes an embedded data URL for the same import. Scene geometry, seed, textures, camera, lighting, bulb wrapping, controls, and train logic are unchanged.

The page wrapper uses the captured styles and a local copy of the original sandbox stylesheet. It removes the already-rendered canvas so the original code can create it again, resets the loading state, omits unused host helpers, and permits normal page scrolling. The scene keeps its original 3:2 aspect ratio.

`original/rendered-app.html` is a serialization of the live DOM, not a claim to the pre-render server file bytes. The scene module itself is preserved exactly as read from its script element.

## Verification

- Original and packaged scene modules match after reversing the single import replacement.
- The standalone edition contains the same scene module and exact Three.js bytes.
- Chrome rendered the source app, single-file edition over HTTP, and Vite production build without console errors.
- Run/Pause changed the control state and visibly moved the train.
- JavaScript syntax checks and Vite production build passed.

The browser automation policy prevents opening `file://` URLs, so direct double-click launch was not automation-tested. The identical standalone file was tested through the local server and has no external asset links.
